# Card: `physics/qec` (error-correction engine)

`app/src/physics/qec/*.ts`, pure TS (no React, no DOM, no clock; seeded randomness only). Numpy twin: `pipeline/qec_numpy.py`, fixtures
`pipeline/make_qec_fixtures.py` -> `physics/__fixtures__/qec.json` (checked by `qec/fixtures.test.ts`). Test helpers: `qec/testkit.ts`.
A new function here gets a numpy twin (a different route), a fixture block and a test. Qubit index 0 = leftmost letter; GF(2) vectors are `number[]` of 0/1.

Gotchas: `Pauli.parse` keeps a phase prefix; `syndrome` is 0/1 per generator in generator order; distances are exhaustive only for small n (a `budget`
cap returns `lower` only, so state "d >= lower" not "d ="); the bicycle distance is NEVER computed here (the paper reports d = 12 and 18: show it as reported,
or exhibit a weight-d operator as an upper bound). Kind `code` shows a code by registry id only; to draw a new code, register it in `registry.ts` first.
