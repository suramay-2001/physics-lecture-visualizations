# Card: stage kinds

A beat's `stage` is data: a `StageState` (`{kind, ...fields}`), or `{layout: 'split', top, bottom}` / `{layout: 'inset', main, inset}` (a layout never repeats a kind).
Types: `app/src/content/stage.ts` (`StageState`, per-kind interfaces; unknown or misplaced fields are rejected by `stage/resolve.ts validateLayout`, with a message naming
the field). Spec (long): `docs/specs/stage-kinds.md`. Field lists for every kind: `docs/context/generated/ids.json` -> `stageKinds`. In Papers a stage may also be a
recipe ref (`{recipe, params}`, card `papers-platform`). Every SVG kind's scene also draws its print figure; `shot` picks a camera/frame preset (leave to the default or copy a neighbour).
`KIND_RENDER`: 448's six kinds are WebGL (`gl`), the rest SVG (`svg`, lazy chunk `stage/svg/kinds.ts`, no WebGL). Course-aware passport/fidelity: `PASSPORT`, `content/fidelity.svg.ts`.

| kind | draws | key fields |
|---|---|---|

| `two-qubit` | two reduced Bloch balls + 3 x 3 correlation grid, CHSH, concurrence | `source, local, condition, arrows, grid, axes, readouts` |
| `plot` | a NAMED curve (never points) with markers/bands, or up to 6 named series | `curve: {fn, x?, samples?}` or `series: {fn, params?, label?}[]` (+ `xRange, samples`), `markers, reportedMarks, bands, yLines, yScale, xScale`; fn from `PlotCurveName` in stage.ts (chsh, nSquared, twoToN, peBest3, repFail3/5, identityP, qhbNeed1, steaneFailX, ...); series fn: `cleanRun, repLogicalVsD, repLogicalVsP, surfaceVsP, surfaceVsD` |

| `clocks` | two phase clocks beside an energy ladder | `levels, start, timeDeg, show, readouts` |
| `wavefunction` (448 L12, used by L13) | a complex function along a line: ψ(x) and φ(p), Re/Im/density/phase, cells, interval, x̂ψ and p̂ψ | `source: {packet:{x0,sigma,p0?}} \| {plane:{p}} \| {twoWaves:{p1,p2}}`, `boost, shift, time, panels, show, overlay, cells, interval, window, readouts` |
| `grover-plane` | Grover's real plane | `search: {n, marked?}, k, half, mirrors, trail, arcs, proof, readouts` |
| `bits` | classical bits: a gate/function table or map, rows (xor/dot), GF(2) row reduction, a bicycle code's check matrix as pixels, a labelled table | exactly one of `fn: {source, view, versus, mark}`, `rows: {strings, combine}`, `reduce: {strings, upTo}`, `bitmap: {matrix: {bb, which}, bands?}`, `grid: {shiftAction: {code, shift}} \| {rows}` |
| `code` | one stabilizer code: a registry id, or the toric / rotated / planar surface code | see below |

## `code` (the error-correction kind, shared by Q21, Q22 and the Papers chapters)

```ts
{ kind: 'code', code: 'steane7', view?: 'layout'|'checks'|'words', error?: 'X5' | 'IIIIXII', show?: ['syndrome','correction','residual','logical'],
  correction?: 'X5', errors?: [up to 8 Pauli strings] /* checks */, word?: 0|1|'plus' /* words */, focus?: number|'X12'|[a,b] /* bicycle */, shift?: [a,b] /* bicycle */ }
```
- `code` is a registry id (`rep3, rep3x, shor9, steane7, five5, surface3, surface5, gross, two-gross`; `physics/qec/registry.ts`), never coordinates. To draw a new code, register it first.
- Layout: numbered discs = data qubits, squares = checks (X and Z in the two letter hues), edges = what a check acts on. `error` writes letters on discs (a Pauli string of length n, or hit qubits counted
  from 1: `"X2"`, `"X1Z4"`). `syndrome`, `correction`, `residual` need an `error` (residual needs `correction`); `correction` defaults to the lookup decoder's, an authored one must have the error's syndrome.
  Bicycle codes (`gross`, `two-gross`) draw an l x m torus tile; only `focus`ed checks (at most 2) get edges (long-range edges are labelled stubs), `shift` draws x^a y^b. `checks` and `words` views: n <= 9.
- Limits: layout <= 25 qubits and <= 24 checks; words view one logical qubit and <= 16 strings. Distances: exact for n <= 25, the bicycle d is the paper's number, REPORTED.
- A lit check means "this check read -1", not "this qubit is broken" (fidelity `qc-code-lit`). Print figure 320 x 360. Passport "CODE · qubits and checks". Shot `CD-CODE`.
- New sources (B1, additive; a state names exactly one of `code`, `toric`, `rotated`, `planar`; qubit numbers are the engine's, from 0; checks are X1 … then Z1 …):
  `toric: {L, M?}` (2-8, one qubit per edge of a wrapped grid, <= 128 qubits), `rotated: {d}` (odd 3-9), `planar: {d}` (the unrotated patch, odd 3-7). Views `'torus'` (toric only: edge qubits at the
  edge midpoints, stars and plaquettes as small squares in the X and Z hues, wrap arrows at the borders) and `'patch'` (rotated: faces and half-discs; planar: the staggered grid with its weight-3 boundary
  checks); the Tanner `'layout'` also works for the small ones (<= 25 qubits, <= 24 checks: a 3 x 3 torus, rotated d = 3 / 5, planar d = 3). No `view` = `'torus'` for a toric source, `'patch'` for the other two.
  Overlays: `fault: {type: 'X'|'Y'|'Z', qubits}` (<= 24; letters, and with `show: ['syndrome']` the checks that read -1: a Z part lights stars / X checks, an X part plaquettes / Z checks);
  `operator` (toric `'z-loop-h' 'z-loop-v' 'x-cut-h' 'x-cut-v' 'plaquette'` + `at`; patch `'xbar' 'zbar'`; always drawn when given) with weight, lit checks and the engine's classification
  ("stabilizer" / "logical operator" / "detected"); `operator2` in a second hue, shared qubits ringed, overlap counted ("overlap 1: anticommute"); `show` adds `'weights'`, `'stars'` / `'plaquettes'`
  (torus highlight; not both), `'logical'` (needs `operator`); `schedule: {xOrder, zOrder}` (rotated, `'patch'` view; orders of `'TL' 'TR' 'BL' 'BR'`): spokes numbered 1-4 by the engine's step order,
  clashes ringed, flagged X/Z pairs outlined, readout `clash-free · valid` / `N flagged pairs` / `clash: n places`. `error`, `correction`, `errors`, `word`, `focus`, `shift` are refused on a new source.
  Limits: <= 8 x 8 torus, <= 97 data qubits, one fault and one operator (+ `operator2`). Fidelity: `qc-code-lit` (reused), `qc-code-schedule-order` (schematic). Code `stage/svg/code.surface.ts`, `CodeSurfaceScene.tsx`.
- `circuit.faults` (<= 24 `{col, wires, label?}`: a diamond on each wire in the slot just before column `col`; `col` = number of columns is after the last; label <= 6 characters) draws places a fault can happen, not
  computed faults (`qc-circuit-fault-markers`, schematic). `circuit.hook: {after: 0-3}`: the leading CNOT columns must share one wire (the check qubit); the fault on it after `after` of them reaches the data wires of
  the CNOT columns still to come (dashed along the check wire, ringed). A larger print figure (`circuitPrintSize`) when either is used.
- `plot` series: see the table row; every y from `physics/qec/curves.ts`; `xScale: 'log'` (positive range; not for a function of d), `reportedMarks` (<= 6, hollow "as printed", from reported claims only), markers on the
  first series, a value table in the readouts, `qc-plot-printed-constants` (misleading if read as a measurement). Limits: <= 6 series sharing one x, d odd <= 399 (a range of d inside 1-99), p a chance.
  `cleanRun` also takes `vote` (odd <= 99: each step protected by a majority vote of that many copies).
- `bits.bitmap` / `bits.grid` (B2): pixels of `gross` / `two-gross` H_X, H_Z or both (one rectangle per run of 1s), bands <= 4, readouts `144 x 144 cells`, `864 ones`, `row weight 6`, `H_X H_Zᵀ = 0`; the 12 x 12 logical
  action of a shift x^a y^b (`|a| <= l`, `|b| <= m`) or an authored table (<= 12 x 12). `qc-bits-bitmap` (exact), `qc-bits-basis-dependent` (misleading).
- `spacetime` (B1): `history.n` 3-9, `rounds` 1-6, `faults` <= 12 `{kind:'data'|'meas', at, t}` (or a seeded `sample: {p, q, seed}`, not both), `show` default `['faults','detectors']` (`'matching'`, `'verdict'` need <= 14 lit
  events), `cursor` 0..rounds+1 (dims later rounds), `spectrum: {maxW}` 1-4 (draws no history: a bar per weight for all / fail / tie; weight 3 needs <= 45 fault places = `rounds*(2n-1)`, weight 4 <= 15; not with faults, sample,
  show or cursor). Readouts: lit events, faults, matching weight, "logical qubit: flipped", "decoder: right | wrong | tie". Passport "SPACE-TIME · detector history"; shot `ST-HISTORY`; anchors `detector fault edge matching
  boundary verdict bar`; print 320 x 300; fidelity `qc-spacetime-engine` / `-layout` / `-repetition-only`. Code `stage/svg/spacetime.ts`, `SpacetimeScene.tsx`.
- `bb` source (B2; `bb: {preset | spec, form?}`, exactly one source per state): views `'cells'` (the l x m torus of 2 x 2 cell blocks, R top-left, X top-right, Z bottom-left, L bottom-right; overlays `check: {kind, cell}` (+ `longEdges` to label the long edges with their offsets), `pattern: {poly 'A'|'B'|'At'|'Bt', anchor}` (ringed cells), `shift: [a, b]` (arrows)), `'layers'` (one X and one Z check from the middle of the torus, edges coloured by thickness-2 layer; three monomials in A and B), `'cycle'` (`cycle: {variant 'printed'|'swap-z-reads', round 1-8}`: edges of the depth-8 cycle in that round, clash and bad-pair counts; <= 144 cells; gross / two-gross need `form: 'bravyi'`). Presets `gross two-gross b72 b90 b108 b144 b288 b360 b756 toy-24 toric-3x3` (`bbfamily.ts`); `spec` = {l, m, A, B} (<= 400 cells, <= 4 terms). Code `stage/svg/code.bb.ts`, `CodeBBScene.tsx`; fidelity `qc-code-bb-layout` (schematic), `qc-code-bb-cycle` (exact).
- `bb.paperOps` (P1, additive; `paperOps?: {ops: string[], shift?: [a, b]}`, only a `bb` source with `preset: 'gross' | 'two-gross'` in its default (toric) form and the `'cells'` view; a `spec`, another preset, `form: 'bravyi'`, another view or another source is refused with a message naming `paperOps`): marks on the l x m cells the L and R qubits in the support of 1-4 distinct logical operators of the paper's basis (`physics/qec/bb.ts paperLogicalBasis`; `ops` names are `'X1'`..`'X12'` (basis.X[i-1]) and `'Z1'`..`'Z12'` (basis.Z[i-1])). X-type in the X hue, Z-type in the Z hue, a qubit in both ringed (it is a Y there); `shift: [a, b]` (|a| <= l, |b| <= m) first translates every operator by the monomial x^a y^b (`code.shiftPermutation(a, b)` on the Pauli, the code's own automorphism; [0, 0] changes nothing, [l, m] comes back). Readouts (appended to the cell view's own): `X̄1 weight 12` per operator (a combining macron), `all shifted by x y^2`, and for every pair `X̄1 and Z̄1 share 1 · anticommute` (X-type with Z-type: commute exactly when the shared count is even; same-type pairs say only `share k`). Gross weights 12, two-gross 20. Print figure: the code kind's 320 x 360 (the extra legend row is allowed for in `codeGeometry`). Passport variant `PASSPORT_VARIANT.codePaperOps` (same title and note as `code`, fidelity key `'code-paper-ops'`): its drawer holds `qc-code-paper-ops` (exact), `qc-code-paper-ops-layout` (schematic), `qc-code-paper-ops-basis` (misleading: the name X̄1 is the paper's choice of basis), registered in `SVG_FIDELITY_VARIANTS` (content/fidelity.svg.ts), NOT in the `code` drawer (whose ids a test pins); a beat showing the overlay can flag only these three ids. Anchor `logical` (reused). Code `stage/svg/code.bb.ts` (`buildPaperOps`, `paperOpsProblems`), `CodeBBScene.tsx` (`PaperOpsMarks`); tests `code.paperOps.test.tsx`.
- `bp` source (B2; `bp: {code 'rep7'|'toric3', error: bit list, p, iter 1-18, osd?, tie?}`, view `'beliefs'`): min-sum BP (and OSD-0) from `physics/qec/bp.ts`; bits filled when the belief says flipped, ringed when the hard decision flips them, true error as X, lit checks, OSD set. toric3 bits: h(i,j) = 3j+i, v(i,j) = 9+3j+i. Fidelity `qc-code-bp-engine` (exact), `qc-code-bp-plain` (misleading: plain min-sum, not the paper's decoder).
- `plot` points mode (B2): `{kind:'plot', points: [{x, y, label?, status?: 'computed'|'reported'|'bound', group?}] (<= 24, <= 4 groups), xLabel, yLabel, xScale, yScale, yLines}`; filled = computed, hollow = printed (reported), hollow with a tick = printed upper bound. Third member of the `plot` union, no curve or series. Code `stage/svg/PlotPointsScene.tsx`; fidelity `qc-plot-points-printed`.
- B3 additions (all engine values from `physics/qec/{gauge,surgery,update,timelike}.ts`; tests beside each scene):
  - `surgery-graph`: `gauge:{host:'patch3-x'|'patches3-xx'|'patch3-steane'|'seam3', rungs? 1-3, w? 1-3, drop?, order?}`, `show?` (vertices edges cycles checks), `focus:{vertex}`, `product`, `subset:'worst'|ids`, `readouts?` (V E cycles cheeger n k distance). Dots = support qubits, links = new qubits, cycles tinted B1.. (dropped ones grey). Passport "GAUGING GRAPH · new qubits"; shot SG-GRAPH; anchors vertex edge cycle check subset link; print 320 x 300; fidelity qc-graph-counts/-layout/-one-choice.
  - `pauli-program`: `program:{wires 1-6, columns <= 24 of {rot:{pauli,angle c+|c-|t+|t-}}|{meas:{pauli,outcome?}}|{inject:{pauli,s?,t?}}, labels? <= 3 chars}`, `upTo?` dims later columns; `compile` / `branch` are B4's (below). Readouts are counts of columns. Passport "PROGRAM · Pauli operations, time →"; shot PP-PROGRAM; anchors wire column rotation meter lane; print 320 x 300; fidelity qc-program-letters/-layout/-magic-lane.
  - `spacetime` readout mode: `history:{mode:'readout', checks 1-8, rounds ODD 1-11, q?, seed?, faults?:[{round,check}] 1-based <= 24}`, `show` of readings product vote; authored faults or `{q,seed}` via `timelike.history`; with q it prints p and the vote failure.   - `code`: id `c422` (square, k = 2, no decoder). `measure:'IZZI'` on the `checks` view adds a measured row and the engine verdict ("commutes with every check · not in the group · k: 2 → 1"). `surgery:{d:3|5, product:'XX'|'ZZ', step:'separate'|'merged'|'split', show?:['new','widened','seam','product']}` is a fifth source (view patch); new / widened / product need step 'merged'; note qc-code-surgery-schematic.
  - `matrix` tableau: rows of 1-4 letters; `update:{generators <= 4 (signs ok), measure, outcome?}` with `tableau: []` draws before / measured P / after with clash marks from `updateRule` (replaced | fixed | added, stored qubits); fidelity qc-update-rule; not with product / values / state / targets / players.
  - `plot` series `voteFail` (params q, m; x = rounds R, odd 1-11) and `xs:[odd ints]`; log y axis and `yLines` as before.
  - `bloch.marks:{points:{x,y,z}[1-24 unit vectors], index?}` draws engine-supplied points as small spheres (ruling papers-B3B4 R4); never computed in content.
  - B4 additions (engine: `physics/qec/{pbc,inject,magic}.ts`; tests `pauliProgramB4.test.tsx`, `stage/b4Extensions.test.ts`):

A module = a code block (area ~ sqrt(c)) over 12 wire dots (two columns, qubits 1-6 and 7-12; qubit 1 the PIVOT drawn filled, qubit 7 ringed) over an LPU block (area ~ sqrt(u), dashed: u is REPORTED, badged 'u reported'); neighbouring LPUs are joined by an adapter bar (width ~ sqrt(a)); the T factory (area ~ sqrt(f), dashed: reported, badged 'f reported') and its adapter a' stand at the END of the line (linear) or in a second row under module 1 (triangular, Fig. 2b; M <= 6). Readouts: `q = 4801 (uses Table 1's u and f)`, `n = 11 M = 110`, `parts` (two rows: `c = 288 · u = 90 (reported) · a = 22`, `a′ = 13 · f = 810 (reported)`), `(c + u)/12 = 31.5 physical qubits per logical qubit` (engine `tdgPerLogical`, added at the end of tdg.ts), `yield` (two rows: `chip yield y^J = 4.6 × 10⁻⁴ (1 in 2170)` from `tdgYield(q)`, and `assumes two couplers per qubit (ours)`; `y^J < 10⁻³⁰⁰` when it underflows). Validation (messages name the field): M a whole number 1-1000; triangular needs M <= 6; `focus` 0..M-2 for 'inter-module' (it needs M >= 2), else 0..M-1; `q` readout and 't-injection' need a factory; <= 5 readouts, no duplicates. ## Related additions that exist

`amplitudes.keep` takes a wire list (`[3, 4]`, marginal over those wires, mode `probability` only); `plot` curves above; `circuit` labels wrap, classical conditions show `c0c1=10`;
`matrix` pair view (`source: {pair…}`, readouts `dims norm params marginals means det product`); `matrix` tableau view for <= 3 qubits (`tableau: …`). A fidelity note
(`exact` / `schematic` / `misleading`, keys like `qc-code-engine`) is registered in `content/fidelity.svg.ts` or `qc709/fidelity.ts`; a beat names it in `fidelity: ['qc-code-lit']`.
Gotchas: a split never repeats a kind; a derivation `view` must use a kind the unit's stage already shows; transitions between different pictures of one kind switch at the half-way point.
