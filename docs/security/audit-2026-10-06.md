# Security audit before making the repo public (2026-10-06)

Scope: the whole repository and its full git history (481 commits). Main HEAD after the fixes is gate-green (5617 tests).

| Check | Result |
|---|---|
| Secrets in any blob or commit message (API keys, tokens, private keys, JWTs, signed URLs, assigned secrets) | **Clean.** `pipeline/audit_public.py`, full history |
| Personal data (home-folder paths, usernames in paths, e-mail addresses, scratchpad paths) | **Clean** |
| Git identities | **Clean.** All 481 commits use the GitHub no-reply address as both author and committer |
| Copyrighted course material | **Clean.** No PDF, EPUB or Office file and nothing under `sources/` was ever tracked. No tracked text shares a 12+ word run with any source text |
| Local config, `node_modules`, worktrees, `.env` | **Never tracked.** Only `course.config.local.example.json`, which is intended |
| Symlinks | **19 tracked**, all relative (`.claude/skills/* → ../../skills/*`) |
| App hardening | Strict CSP (`default-src 'none'`, no inline scripts, `frame-ancestors 'none'`), HSTS, and a no-eval / no-HTML-sink test. 0 CSP violations and 0 third-party requests per the security e2e |
| Dependencies, `app/` (ships to users) | **Fixed.** `source-map-js` < 1.2.2 (GHSA-68fv-2mgg-jv7q, high, DoS via crafted source maps), updated by `npm audit fix`. 0 vulnerabilities remain. Build-time only; not in the bundle |
| Dependencies, `films/` (local film rendering only) | **4 high remain, accepted:** `braces` (GHSA-vfj7-8cjw-p6xm), `micromatch`, `fast-glob` and `@motion-canvas/vite-plugin`. They are DoS bugs triggered by attacker-controlled glob patterns in a local dev tool; nothing ships to users and the inputs are our own. The fix needs a major upgrade of `@motion-canvas/vite-plugin` (→ 3.11.0); do that upgrade together with a film re-render test |
| Large files | No file over 10 MB. The `graphify-out/` graph snapshots are 6–9 MB each, which is repo bloat but not a security risk |
