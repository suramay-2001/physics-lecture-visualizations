## 3. F1 addendum

**3.1 Simpler Ground-up.**
- **`f1-phase:b4` gains D7**, from N&C's argument that a common size-1 factor cancels (§2.2.7, p. 93).
  - Ground:
    1. `e^{iγ}A + e^{iγ}B = e^{iγ}(A + B)`: turning both arrows by γ turns their sum by γ.
    2. `|e^{iγ}| = 1`: a pure turn sits on the unit circle.
    3. `|e^{iγ}(A + B)| = |e^{iγ}||A + B|`: sizes multiply (D3).
    4. `= |A + B|`: multiplying by 1 changes nothing.
    5. `|e^{iγ}(A + B)|² = |A + B|²`: a chance is a size squared, so no chance changes.
  - Formal: `⟨ψ|e^{−iγ}M†M e^{iγ}|ψ⟩ = ⟨ψ|M†M|ψ⟩`, for every outcome. Claims: reuses `f1Global`.
- **`f1-multiply:b4` gains** (N&C treat size-1 multipliers as pure phases, p. 85):
  - G: "Dividing $3 + 4i$ by its size 5 gives $0.6 + 0.8i$, an arrow of size 1 pointing the same way. So every number
    is its size times a pure direction."
  - F: "Every $z \ne 0$ factors as $|z|\cdot(z/|z|)$ with $z/|z| \in S^1$."
  - Claim `f1Dir34`: `div(c(3,4), c(5))` → (0.6, 0.8); `abs` → 1.
