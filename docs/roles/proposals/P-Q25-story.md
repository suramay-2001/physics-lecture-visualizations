**b4 [B]** (the π–2π–π gate, p. 235, Fig. 13.7; D5; Bridge `qc-q4-cnot`)
- G: "Pulse the control atom by π, the target by $2\pi$, the control by π. A single atom in the pulsed level gets $-1$. If both are up, the control's excitation blocks the target. The result is $\mathrm{diag}(1, -1, -1, -1)$."
