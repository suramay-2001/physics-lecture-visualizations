## 2. Derivations (one track; ≥ 2 distinct views; kinds on each unit's stage)
- **D1 `l17-mean-force:b2`** result `\langle F\rangle = F(\langle x\rangle)\ \text{for}\ F = \alpha+\beta x`: (1) `F(\hat x) = \alpha + \beta\hat x` view W; (2) `\langle F\rangle = \alpha+\beta\langle x\rangle` — "an average of a linear function is the linear function of the average"; (3) `= F(\langle x\rangle)`, view W harmonic; (4) so `m\,\ddot\mu = F(\mu)` exactly.
- **D2 `l17-mean-force:b4`** result `m\ddot\mu = F(\mu)+\tfrac12F''(\mu)(\Delta x)^2+\dots`: (1) `F(\mu+\delta x) = F(\mu)+F'(\mu)\delta x+\tfrac12F''(\mu)\delta x^2+\dots` view W; (2) average term by term, `\langle\delta x\rangle = 0`; (3) `\langle\delta x^2\rangle = (\Delta x)^2`, view W σ sweep; (4) result; for `F=\gamma x^2`, `F''=2\gamma` gives `\gamma(\Delta x)^2`.
- **D3 `l17-step:b3`** result `r = \tfrac{k_1-k_2}{k_1+k_2},\ \mathsf t = 1+r`: (1) the three waves, view W; (2) `A+B = C` (φ continuous); (3) `k_1(A-B) = k_2C` (φ′ continuous), view CP; (4) insert `C = A+B`: `(k_1-k_2)A = (k_1+k_2)B`; (5) divide by `A`: result.
- **D4 `l17-current:b2`** result `\partial_t\rho + \partial_xj = 0`: (1) the SE and its conjugate; (2) `\partial_t\rho = \psi\,\partial_t\psi^*+\psi^*\partial_t\psi`; (3) put them in: `V` cancels, `\partial_t\rho = \tfrac{i\hbar}{2m}(\psi^*\psi''-\psi\psi^{*\prime\prime})`; (4) it is `\partial_x(\psi^*\psi'-\psi\psi^{*\prime})`; (5) name `j`. Views W free packet at rest and moving (as the moved `l13-flow:b1`).
- **D5 `l17-current:b4`** result `j_{\rm left} = \tfrac{\hbar k_1}{m}(|A|^2-|B|^2)`: (1) `\varphi = Ae^{ik_1x}+Be^{-ik_1x}`, view W twoWaves; (2) `\varphi^*\varphi' = ik_1(|A|^2-|B|^2)+ik_1(B^*Ae^{2ik_1x}-A^*Be^{-2ik_1x})`; (3) the bracket is `z - z^*`, purely imaginary, view CP; (4) `\mathrm{Im}(\varphi^*\varphi')` keeps the first term; (5) times `\hbar/m`.
- **D6 (check on `l17-current:b5`)** a short derivation block, not a new beat: result `R+T = 1`: (1) `R = |r|^2`, `T = (k_2/k_1)|\mathsf t|^2`; (2) put in `r`, `\mathsf t`; (3) `\tfrac{(k_1-k_2)^2+4k_1k_2}{(k_1+k_2)^2}`; (4) `=1`. Views PLOT `stepR`, `stepT`.
